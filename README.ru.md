# Glass OCR

[English](README.md)

Локальный конвертер PDF для macOS на Apple silicon и Windows x64/ARM64. Перетащи скан или PDF с выделяемым текстом в окно браузера, которое открывает лаунчер. OCRia-nano-1 через LiteParse определяет русский и английский автоматически, по строкам. Язык интерфейса переключается между русским и английским.

| Формат | Что получится | Что требуется |
|---|---|---|
| .docx | Редактируемый текст и таблицы | LiteParse |
| .xlsx | Отдельный лист на каждую найденную таблицу, с объединёнными ячейками, если они распознаны | LiteParse |
| .doc | Бинарный документ Word 97–2003 | Встроенный конвертер macOS, LibreOffice на Windows |
| .pages | Нативный документ Apple Pages | macOS, Apple Pages и разрешение на автоматизацию |

Приложение слушает только локальный адрес. PDF обрабатывается на устройстве во временной папке, которая очищается после каждой задачи. Интернет нужен при первой загрузке зависимостей и весов. Утилита распространяется в виде исходников со скриптами запуска.

## Установка

Установи [64-битный Python 3.11–3.14](https://www.python.org/downloads/). Для macOS выбери Python, который работает в режиме arm64. Скачай или клонируй репозиторий и открой терминал в его папке. Перед скачиванием весов прочитай [лицензию модели](https://huggingface.co/llamaindex/OCRia-nano-1/blob/v1.0.0/LICENSE).

### macOS

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m liteparse.cli models pull ocria-nano
sh start-mac.command
```

### Windows (PowerShell)

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m liteparse.cli models pull ocria-nano
.\start-windows.bat
```

После установки запускай последнюю команду или дважды щёлкни по скрипту. Чтобы закрыть утилиту, закрой терминал. Для .doc на Windows установи [LibreOffice](https://www.libreoffice.org/download/download-libreoffice/) в стандартную папку или добавь его в PATH. Для .pages установи Apple Pages и при запросе macOS выдай разрешение на автоматизацию. Можно также открыть результат DOCX в Pages и сохранить его вручную.

## Конвертация

Перетащи один PDF до 125 МиБ, выбери формат и нажми **Конвертировать PDF**. Для отдельных страниц укажи диапазон, например `1-3, 5`. В **Настройках распознавания** можно поменять DPI, выключить распознавание сканов для PDF с текстовым слоем или сохранить колонтитулы.

Утилита восстанавливает редактируемый текст и структуру таблиц. Сложная вёрстка может упрощаться, изображения, точная типографика и ссылки могут теряться. Проверяй результат OCR, особенно короткие числа в таблицах на сканах. В Excel ячейки сохраняются как текст, чтобы содержимое документа оставалось данными, а ведущие нули сохранялись. Для вычислений преобразуй нужные ячейки в числа в Excel.

## Проверка

Команда `python -m unittest -v` проверяет XML внутри файлов Word и Excel, объединение ячеек, кириллицу, сохранение данных как текста, передачу настроек в LiteParse и локальный HTTP-интерфейс. GitHub Actions запускает эти проверки на macOS и Windows без скачивания весов.

На Apple M1 Pro LiteParse 2.21.2 с OCRia-nano-1 1.0.0 проверен на двух одностраничных двуязычных PDF. Скан обработался примерно за 0,29 с внутри LiteParse при 250 DPI. Модель распознала оба языка и структуру таблицы из пяти строк, но три значения количества были ошибочными или пустыми. В PDF с текстовым слоем количества сохранились, однако встречались подмены нескольких кириллических букв. Одного чистого скана мало для сравнительного бенчмарка.

## Модель и лицензия

OCRia-nano-1 от LlamaIndex, Inc. запускается через [LiteParse](https://github.com/run-llama/liteparse). См. [карточку модели](https://huggingface.co/llamaindex/OCRia-nano-1) и [технический отчёт](https://www.llamaindex.ai/ocria/ocria-nano-1-report.pdf). Оригинальные веса скачиваются отдельно и используются без изменений. LiteParse сохраняет копию лицензии рядом с весами. Перед использованием в продукте или сервисе проверь условия коммерческого использования и ограничения для конкурирующих сервисов.
